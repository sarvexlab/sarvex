---
title: Orders
description: Orders placed by shopping agents show up under Store, each linked back to the checkout session that produced it.
---

**Orders** placed by shopping agents show up on the **Orders** tab under **Store**, alongside your regular orders — Sarvex mirrors what your store recorded rather than running a separate order system. The tab stays empty until your store is live for agents; the first agent checkout appears here the moment it lands.

Each order shows when it was placed, its value, its status and sync state with your store, and your store's own order reference once recorded. Every order links back to the checkout session that produced it, so you can trace exactly how it happened if anything looks off.
