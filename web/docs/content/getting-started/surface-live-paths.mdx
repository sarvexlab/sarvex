General going live — reaching **Active** on Path — doesn't depend on any individual agent surface. See [Going live / validation](/getting-started/going-live-validation).

Each agent surface has its own review process and live path. Dedicated pages for each surface are coming; until then, here is what the validation pipeline currently shows for Google:

- **Google sandbox** and **production** track your store's status in Google's own review process for its agent surfaces, shown on the Validation screen for visibility — Google gates these, not Sarvex.
