---
title: Installing the WooCommerce plugin
description: Download, upload, activate, and configure the Sarvex UCP Gateway plugin.
---

1. Download the plugin from the link Sarvex gives you.
2. In WordPress Admin, go to **Plugins → Add New → Upload Plugin** and upload it (or drop the folder into `wp-content/plugins/` directly).
3. Find **Sarvex UCP Gateway** under Plugins and click **Activate**.
4. A **Sarvex UCP** menu appears in WordPress Admin — that's where you'll configure everything.
5. In that settings page, enter your **Sarvex Endpoint URL** (given to you by Sarvex, e.g. `https://api.sarvex.io`) and save. The plugin needs this before pairing will work.
