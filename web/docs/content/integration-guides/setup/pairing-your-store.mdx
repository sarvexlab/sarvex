---
title: Pairing your store
description: Pairing is driven from the Sarvex console — the console generates the code, and you hand it to the plugin or module.
---

The Sarvex console generates the pairing code; you enter it in the plugin or module.

1. In the console, open **Connect** and generate a pairing code and connector ID.
2. Enter both in your store:
   - **WooCommerce:** in WordPress, go to **Plugins → Sarvex → Pairing**.
   - **Magento:** in Magento Admin, go to **Stores → Configuration → Services → Sarvex UCP Gateway**.
3. Back in the console, click **"I've entered the code in the plugin"** to verify the connection — no manual refresh needed.
4. Once it confirms, you're paired.

From here, connection state lives on [Path](/getting-started/your-setup-path). If pairing ever breaks later, it shows up there as a task rather than something you need to actively monitor.
