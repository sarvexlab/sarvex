---
title: Going live checklist
description: What has to pass before agent checkout turns on for your store.
---

Agent checkout turns on once your store passes Sarvex's validation checks — catalog readiness and a working, paired connection, among others.

Run validation from **Path** or the **Validation** screen; each check reports pass or fail, with what to fix. Common things that hold it up:

- Products missing fields agents need — check each product's readiness state under **Store**
- The connector not currently paired or reachable
- Recent sync issues flagged under **Health**

Once everything passes, checkout goes live automatically.
